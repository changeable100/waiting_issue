# 校园外卖柜模型阶段进展汇报

汇报人：邹佩希　汇报日期：2026年11月7日

程序可以输出满柜投递等待、学生操作排队、到柜至取餐完成延迟、柜体占用轨迹、时间加权利用率和满柜时间占比。到达与延迟样本可由数据成员替换，系统成员可通过稳定的 Python 接口调用；真实数据和线上服务尚未接入。

本阶段新增第五步本地网页演示，已支持场景选择、容量调整、模型调用、图表显示和JSON导出，具体见 `05_local_web.md`。现有16项模型测试与新增8项服务测试共24项通过；浏览器已验证默认运行、容量变化、非法输入提示与导出。正式Flask服务及微信小程序仍待团队集成，本地演示不改变研究精度待真实数据验证的状态。

建模中需要统一的事项是：申请书 tw 混合了投递前满柜等待与学生到柜排队，T2 也存在到柜与入柜两种表述。当前模型将两类等待分开，把 T2 定义为到柜时刻，单列入柜时刻，并引入可配置的取餐操作资源。这一处理避免已入柜订单因满柜而无法取走的循环等待，需经评审确认后作为正式论文口径。

验证方面，16项自动测试覆盖了手算案例、边界、时序和守恒；960次合成仿真验证了多情境实验流程。没有真实数据时不报告预测准确率，也不将合成扩容效果作为实际部署建议。申请书的误差、覆盖率和改善目标目前均为后续研究目标。

下一阶段拟在确认口径后，接收匿名观测数据并完善初始占用处理，按日期划分拟合与留出数据完成校准，再与系统、优化和论文成员联调。本轮各步骤的具体进展、验证依据和局限已分别记录，供逐项检查。
