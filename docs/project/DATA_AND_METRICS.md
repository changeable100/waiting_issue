# 数据及指标约定

所有时长统一为分钟，相对时刻以观测窗口开始为0。当前原型到达窗口结束后继续排空，以免删除等待最长的订单。窗口初始状态当前为空柜，真实应用需补充初始占用或预热。

## 来源

配置注明source_kind：synthetic、observed、literature或mixed，并用provenance记录来源、日期范围、版本及变换。混合数据需逐字段解释来源。当前开发分支全部示例为synthetic；其中天气与其他情境系数是工程测试假设，未经实测标定。

文献参数、问卷自报和现场观测分开保存。按日期划分拟合与留出集，避免同日轨迹同时进入两类数据。缺失时间不可填零，无法观察的量应标记缺失并说明处理方式。模板见data/templates/observations_template.csv。

## 指标

| 字段 | 含义 |
| --- | --- |
| deposit_wait_min | 订单到柜至可入柜的等待，主要对应满柜投递阻塞 |
| student_queue_wait_min | 学生到柜后等待取餐操作的排队时间 |
| total_queue_wait_min | 上述两类等待之和 |
| arrival_to_pickup_min | 到柜至取走总延迟，含通知、步行、排队与操作 |
| utilization | 到达窗口内占用格口时间积分除以容量和窗口长度 |
| full_time_fraction | 到达窗口内满柜时长占比 |

p50/p90/p95为经验分位数，不是置信区间，也不代表已经校准的预测覆盖率。零订单时均值和分位数为null，不能展示为零等待。真实MAE与覆盖率必须在相同指标口径的独立留出观测上评估。

T2当前指订单到柜，入柜时刻单列；T1至T2由上游时长输入，缺失时相关输出为null。申请书tw与T2含义需统一评审，当前定义为工程实现约定。扩容减少投递阻塞并不保证学生操作排队同步下降。

## 数据上传

仅上传已获授权并匿名化的数据。不要上传姓名、学号、电话、邮箱、取件码、精确个人轨迹或运营方未授权原始记录。测试夹具、汇总统计与匿名字段模板可以随代码共享；原申请书保留本地，不直接入库。
