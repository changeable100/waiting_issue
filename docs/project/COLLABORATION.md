## 分支使用

main作为公共资料入口。邹佩希分支为zpx/model-development，提交其代码、报告与合成实验；其他成员可自行建立各自分支。不要将个人开发分支整体合入main，除非团队明确改变main的职责。

克隆指定开发分支：

```powershell
git clone --branch zpx/model-development https://github.com/changeable100/waiting_issue.git
```

已有仓库可先git fetch origin，再切换到目标远程跟踪分支。公共文档更新后，个人分支按需合并origin/main；遇到README等冲突保留个人运行说明及公共文档链接。提交前先查看git status与差异，运行与改动相关的检查，不提交依赖和凭据。

## Agent交接

邹佩希分支的 `docs/agents/` 为四名成员分别提供任务说明；先读公共架构和具体接口，再根据职责实现独立模块。不得将文档中“建议”“待实现”的内容描述为既有完成结果。跨模块变更需要记录字段、单位、版本及调用示例，变更指标口径须同步前端、优化和论文。

阶段报告包含实际完成内容、代码与数据版本、检查方法、结果、局限及下一步；不使用收件人称呼，遵循AGENTS.md的报告用语约定。
