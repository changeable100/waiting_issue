# 项目目标与计划

项目名称为校园外卖柜优化建模与仿真，目标是研究取餐等待及柜体资源配置，并形成具有可复现实验支撑的论文成果。软件、数据说明和演示原型用于支撑研究验证与成果展示。

## 研究范围

以“外卖到柜—入柜—通知—学生到柜—取餐—释放”为核心流程，使用经验到达轨迹及延迟样本进行离散事件仿真，考虑工作日/周末、晴/雨、午/晚峰和普通/考试周等情境。后续以真实观测校准参数并比较不同配置。

## 申请书研究目标

在具备足够实测数据的条件下，检验等待时间预测MAE能否达到3—5分钟、预测区间覆盖率能否达到80%；比较不少于3组柜体或格口方案，研究高峰等待降低10%以上的可能性。这些是待验证目标，不能据合成实验宣称已经达成。
