# 陈子吉的 agent 对接任务

申请书分工为编程实现与论文撰写。建议本次对接承担研究验证、论文实验整理，与模型核心实现解耦；若团队另有分工请先按已确认分工执行。

先读 `README.md`、`docs/01_scope_and_plan.md`、`docs/02_contract.md` 及 `reports/`。可引用的当前证据为 `results/test_log.txt`、`results/experiments.csv`、`results/experiments.json`、`results/single_run.json`。所有随附实验均为 synthetic，不能作为北邮真实运行效果的实证。

在 `research/` 或独立论文目录维护实验协议、图表和结果讨论。用 `python run.py demo` 重现实验。图表应注明单位、参数来源、情境、重复次数、种子和容量；Qk(t) 取自单次 trace，利用率取时间积分结果，不能对事件记录直接平均占用数。

真实数据到位后按观测日期划分拟合和留出集。调用 `locker_model.evaluation.evaluate` 计算 MAE 与区间覆盖率，保持实际值和预测值等待口径一致。区间端点要有构建方法；p50 与 p90 不能直接组成声称 80% 覆盖率的区间，当前工程结果没有校准区间。真实验证和合成实验分开出表。

研究讨论应说明：初始空柜偏差、通知后出发假设、独立延迟抽样、固定分柜、无弃单/错拿/超时、上游配送链为输入而非模型；申请书对 tw 与 T2 的歧义需要团队确认。现有模型不支持反向预测 T1，论文不得描述为已实现。

验收：可复现结果与图表、每项结论的对应数据、真实/模拟来源标签、目标是否达成的实际统计；没有真实数据时明确保留验证为空。引用实际文献需核验来源，不把申请书未经核验的市场数字当文献证据。
